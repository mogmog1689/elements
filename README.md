# 元素マスター (Element Master) - 周期表暗記クイズアプリ

Galaxy A22 5G (Android) の表示に最適化された、周期表暗記クイズ用プログレッシブ・ウェブ・アプリ (PWA) です。GitHub Pages にそのまま配置するだけで公開できます。

---

## 📱 主な機能と特徴

1. **2つのクイズ出題モード**
   - **記号モード**: 元素記号・カード情報を見て元素名を4択から解答
   - **順番モード**: ある元素の「次の原子番号」または「前の原子番号」の元素名・記号を4択から解答

2. **細やかな出題範囲・順序設定**
   - 全元素（1〜118番）
   - **族別**（1族〜18族を任意選択可能）
   - **周期別**（第1周期〜第7周期を任意選択可能）
   - **ランタノイド系列**（La〜Lu）
   - **アクチノイド系列**（Ac〜Lr）
   - **昇順（↑）/ 降順（↓）** の切り替えに対応

3. **語呂合わせヒント機能（外部ファイルで編集可能）**
   - 「水兵リーベ」「エッチでリッチな母ちゃんが…」など、標準的な日本の語呂合わせをヒントとして表示。
   - `data/mnemonics.json` に族・周期・系列ごとの語呂合わせを外部ファイル化しているため、自分好みのフレーズに簡単に編集・追加できます。

4. **118元素の詳細解説と画像表示**
   - 問題中および解答後の解説画面で元素カードと代表画像（または美麗プレースホルダー）を表示。
   - 解説には **特徴**、**利用用途**、**1gあたりの参考価格（円）**（人工・放射性元素には注記）を明記。
   - 元素データは `data/elements.json` で管理。

5. **学習記録・履歴管理（オフライン対応）**
   - 日時ごとのクイズ結果、正答率、最大ストリーク（連続正解数）を記録。
   - 間違えた元素を自動集計し、**「苦手な元素 TOP10」** を表示。
   - `localStorage` を利用するため、端末内に永続保存されます。

6. **PWA & Galaxy A22 5G 最適化**
   - ノッチ・パンチホール対応のセーフエリア（Safe Area）配慮。
   - 画面幅・タッチターゲット（48px以上）を配慮したダーク系UI。
   - Service Worker (`sw.js`) と Web App Manifest (`manifest.json`) を搭載し、ホーム画面に追加してアプリとして起動可能。

## 📂 ディレクトリ構成

```text
e-Elements quiz/
├── index.html              # アプリ本体（全画面SPA構造）
├── manifest.json           # PWAマニフェスト設定

├── README.md               # 本ドキュメント
├── css/
│   └── style.css           # Galaxy A22 5G最適化・ダーク系スタイル
├── js/
│   ├── app.js              # UI制御・画面遷移
│   ├── quiz.js             # クイズ出題・正誤判定エンジン
│   └── storage.js          # 学習履歴・苦手元素集計ストレージ
├── data/
│   ├── elements.json       # 全118元素データ（解説・用途・価格・画像指定）

    ├── icons/              # PWAアプリアイコン (192px, 512px)
    └── elements/           # 元素写真・イラスト配置先 (WebP/PNG等)
```

## 🚀 GitHub Pages への公開手順

1. 本フォルダ内のファイル一式を Git リポジトリにコミットします：
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Element Master PWA"
   ```
2. GitHub で新しいリポジトリ（例: `elements-quiz`）を作成し、リモートにプッシュします：
   ```bash
   git remote add origin https://github.com/<あなたのユーザー名>/elements-quiz.git
   git branch -M main
   git push -u origin main
   ```
3. GitHub リポジトリの **[Settings]** > **[Pages]** を開きます。
4. **Branch** で `main`（または `master`）、フォルダを `/ (root)` に設定して **[Save]** をクリックします。
5. 数分後、発行された URL（`https://<ユーザー名>.github.io/elements-quiz/`）にスマホの Chrome からアクセスします。
6. ブラウザメニューの **「ホーム画面に追加」** または **「アプリをインストール」** をタップすると、Galaxy A22 5G のネイティブアプリのように全画面で利用できます。

## ✏️ 語呂合わせや元素データのカスタマイズ

- **語呂合わせを変更したい場合**:  
  `data/mnemonics.json` をテキストエディタ等で開き、各族（`groups`）や周期（`periods`）の `"mnemonic"`（フレーズ）や `"explanation"`（解説）を修正して保存・プッシュするだけで即座に反映されます。
- **元素の画像を追加・変更したい場合**:  
  `images/elements/` ディレクトリに、`data/elements.json` の `"image"` キーで指定されているファイル名（例: `hydrogen.webp`, `gold.webp`）で画像を配置してください。画像が存在しない場合でも、自動的に各元素カテゴリカラーに合わせた美しいプレースホルダーカードが表示されます。
